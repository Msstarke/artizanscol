# Feature Fix List

High-level feature areas that still need work.

## 1. Account Setup and Settings

The account area still needs to move from a dense settings wall to a guided setup flow with a cleaner long-term settings experience.

## 2. Profile Publishing

Artist profiles need a stronger publish model so live profiles always reflect saved data, incomplete drafts are handled properly, and public visibility behaves predictably.

## 3. Explore and Discovery

Public discovery still needs refinement so live profiles surface reliably, filtering feels solid, and empty states never make the platform feel broken.

## 4. Public Profile Experience

Artist profile pages still need to feel more complete, trustworthy, and portfolio-led instead of looking like a thin text-first shell.

## 5. Booking Flow

The booking flow needs better clarity, stronger failure handling, and a more polished end-to-end request experience for both clients and artists.

## 6. Messaging and Notifications

Threads, unread states, and update visibility still need a more usable product experience even though the server-side base is now in place.

## 7. Auth and Session Security

Authentication still needs stronger abuse protection, better session handling, and reduced browser exposure for sensitive auth state.

## 8. Legal, Trust, and Support

The platform still needs real legal content, stronger trust signals, better FAQ depth, and a more complete support/contact experience.

## 9. Frontend Polish

There is still visible polish work across placeholders, empty states, mobile behavior, page consistency, and general production finish.

## 10. Accessibility

The site still needs a focused accessibility pass across forms, navigation, state changes, and public profile/discovery interactions.

## 11. Deployment and Operations

The deploy pipeline and production verification path still need ongoing hardening so stale releases, routing drift, and runtime issues are caught earlier.

## Recommended Order

1. Account setup and settings
2. Profile publishing
3. Explore and public profile experience
4. Booking, messaging, and notifications
5. Legal, trust, and auth hardening
