    Before you send

    Make the request easy to accept.

    • Name the kind of work you need so the artist can assess fit quickly.
    • Add a realistic deadline and budget based on scope.
    • Explain the brief clearly so the artist can respond without back-and-forth.
    Tip

    Strong requests usually include intended usage, preferred style, must-have deliverables, and any key reference material.
